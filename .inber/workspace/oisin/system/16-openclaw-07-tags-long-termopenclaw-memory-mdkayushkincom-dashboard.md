- Protected dashboard at /dashboard with passphrase auth
- Login at /login, JWT session cookie
- Backend endpoints: /api/login, /api/logout, /api/me
- WebSocket at /ws (JWT validated)
- Panels: Si Chat (/dashboard/si), Stats, Notes
- Frontend: React + Vite + TypeScript, AuthProvider wrapping app
- **Architecture**: Dashboard → kayushkin-server /ws → si → bus (inbound) → bus-agent (WSL) → inber → bus (outbound) → si → dashboard
- **NO INBER ON SERVER** — inber only runs locally on WSL, accessed via bus
- WebSocket adapter on :8090 for Claxon Android
- History should come from logstack, not si (si is stateless now)
- **Orchestrator-primary UI**: OpenClaw 🦞 / Inber 🌿 tabs as primary nav. Agent sub-tabs only shown when >1 agent per orchestrator. CSS: `orchNav`/`orchTab`. Usage page also grouped by orchestrator.
